# 計畫：全站改版 第二階段（教練列表、個人頁、服務流程）

分支：develop
日期：2026-11-23
狀態：草稿（等使用者同意後開工）
前一階段：docs/plan-redesign-phase1.md

## 需求摘要（使用者已確認）

1. 教練列表頁、三位教練個人頁、服務流程頁套用第一階段設計（深海藍＋珊瑚、襯線標題、卡片樣式），
   手機優先，電腦版與手機版一致，與首頁看起來是同一個網站。
2. 三個個人頁合併成一個共用版型，網址不變（`/coaches/isaac`、`/coaches/pauline`、`/coaches/vincent`）。
3. 個人頁加「預約初次會談」按鈕：名字下方一個、介紹看完的地方一個，都連到同一個 Google 表單。
4. 服務頁「會談須知與承諾」改成精簡清單（圖示＋標題＋說明），全部展開，不收合。
5. 頭像先用字母（I／林／哲），版型預留照片位置，之後有照片可直接換。
6. 文字沿用上一輪修好的版本；和第一階段一起 release。

## 範圍

- 這次要做：`CoachesIndexView.vue`、三個個人頁 → 一個 `CoachProfileView.vue`、`ServicesView.vue`、
  `router.js`（三個個人頁路由指向同一個版型）、新增 `src/data/coaches.js`、
  三語 locale（新增個人頁底部預約區的文字）。
- 不做：首頁、導覽列、頁尾、新增路由、改寫教練本人的介紹文字、教練照片。

## 技術做法

- **教練資料集中一份** `src/data/coaches.js`：id、路由、i18n key 前綴、頭像字、英文名／中文名（個人頁頂部用）、
  Email、社群連結（類型、網址、顯示文字）。個人頁版型讀這份資料。
  首頁、教練列表、服務頁目前各寫一份教練清單（頭像字、標籤 key、Email…），**這次一起改成讀同一份**，
  避免四處資料不一致（上一輪 QA 的頭像字問題就是這樣來的）。← 這點是範圍擴大，請一併確認。
- **路由**：三條既有路由保留，元件都指向 `CoachProfileView.vue`，用 `props: { coachId }` 區分；
  未知的 `/coaches/xxx` 仍然顯示 404。
- **個人頁版型**
  - 頂部：深海藍漸層帶，頭像、英文名＋中文名、頭銜、兩個專長標籤、珊瑚色預約鈕、Email／社群小按鈕。
  - 內容（手機單欄、由上到下）：關於我（引言＋內文）→ 專注領域 → 教練風格 → 專業背景 → 引言卡 → 教練服務（適合誰）→ 底部預約卡。
  - 電腦（≥ 960px）：左欄主內容（關於我、引言卡、教練服務），右欄側卡（專注領域、風格、背景、聯絡），
    底部預約卡橫跨兩欄。右欄不黏著：側卡可能比視窗高，黏著會讓底部的聯絡區看不到（獨立審查指出）。
- **教練列表**：標題區靠左、與首頁區塊標題一致；三張教練卡（頭像、名字、頭銜、標籤、三行介紹、「查看個人介紹 →」），
  手機單欄、平板兩欄、電腦三欄；ICF 認證區改成淡藍底面板（ACC、PCC 兩張卡＋教練心態引言）。
- **服務頁**：標題區靠左；三個步驟手機為直式時間軸、電腦為三欄；會談須知改成兩欄（手機一欄）的圖示清單；
  「找你的教練」三張卡與教練列表卡同款，附預約、Email、社群按鈕（≥ 44px）。
- 共用樣式沿用 `style.css` 的 token，不新增全域 class；各元件 `<style scoped>`。

## 新增文字（三語）

| key | en | zh-TW | zh-CN |
|---|---|---|---|
| `profile.cta_title` | Want to talk with {name}? | 想和 {name} 聊聊嗎？ | 想和 {name} 聊聊吗？ |
| `profile.cta_desc` | A 45-minute online session for the price of a coffee. | 45 分鐘線上會談，一杯咖啡的費用。 | 45 分钟线上会谈，一杯咖啡的费用。 |
| `profile.contact` | Contact | 聯絡方式 | 联系方式 |

`{name}` 填教練的名字（Isaac／Pauline／阿哲；英文 Vincent）。

## 驗收條件

- **AC-1** 三個個人頁版型相同，只有內容不同；網址不變；`/coaches/不存在` 仍顯示 404。
- **AC-2** 個人頁名字下方與內容最後各有一個「預約初次會談」，開新分頁到同一個 Google 表單。
- **AC-3** 手機（375、390px）個人頁單欄，頂部資訊（頭像、名字、頭銜、預約鈕）在第一個畫面內；
  電腦（≥ 960px）兩欄，右欄側卡內容完整可見、不被頂欄蓋住。
- **AC-4** 教練列表：手機一欄、平板兩欄、電腦三欄；整張卡可點、可長按開新分頁；ICF 區塊為新樣式。
- **AC-5** 服務頁：步驟手機直式、電腦三欄；會談須知 6 項全部展開、每項有圖示；教練卡按鈕對齊、觸控區 ≥ 44px。
- **AC-6** 三頁深色模式文字都清楚可讀，沒有寫死的白字／舊色。
- **AC-7** EN／繁／简 三語下新文字都有翻譯，沒有顯示 key；英文長字不撐破版面。
- **AC-8** 首頁、教練列表、服務頁、個人頁顯示的教練資料（頭像字、頭銜、標籤、Email、社群）一致。
- **TAC-1** 不新增 npm 套件；`npm run build` 成功；console 無錯誤；375／768／1280px 無水平捲動。
- **TAC-2** 只用 `<script setup>`、`<style scoped>`、JS；舊的三個個人頁檔案以 `git rm` 移除。
