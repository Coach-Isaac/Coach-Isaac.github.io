# Design references

Reference material from the brand owner for the Stepflect logo exploration (November 2026).
These files are **not** brand assets: do not crop them into logos or use their lettering.
The official logo is the vector in `src/components/BrandLogo.vue` and `public/favicon.svg`;
rules are in `docs/design-spec.md`.

- `logo-concepts-reference.png`: six minimal logo directions (多重路徑, 反思與前進, 向前一格,
  自主選擇, 進一程, 下一步). They were redrawn as vectors for review; 向前一格 was chosen on
  2026-11-25.
